# v0.7.2 — A layer can release a draft comment

`getService("ticketService")` hands a layer the extension-facing surface, which
exposed only three `*ForExtension` methods. A layer wanting to release or
discard a draft had nothing to call — and calling core's internal service name
failed at runtime with no way to know beforehand.

`publishTicketCommentForExtension` and `discardTicketCommentForExtension` join
that surface. A layer holds a service object, not an HTTP client to its own
process, so this belongs on the service rather than being reachable only
through a route.

## Why this shipped broken

A layer's own tests stub the service, so they mocked exactly the boundary that
was wrong and stayed green through a release. The guard is an integration test
that drives the real layer route against the real core service — the only shape
of test that fails when this surface drifts. Mutation-verified: removing the
method reproduces the production 500.
