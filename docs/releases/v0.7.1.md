# v0.7.1 — A machine token can say which machine it is

## `/api/auth/me` returns the machine account

A machine token resolves `req.user` from its owner, so the endpoint answered
"you are Piotr" for every one of Piotr's agents. With two agents belonging to
one developer — the ordinary case, one per tool — nothing could tell you which
token you were holding.

The response now carries the account id, its name and the granted scopes
whenever the caller is a machine. A human sees no such block.

## A machine-authored comment reads "Agent (owner)"

The account's own name is noise to whoever reads a ticket: "MacBook Agents AI"
says nothing about whether to trust the analysis. The owner does, because the
owner is who answers for it.

## Fixes

Two frontend tests had been red since the extension ticket sections landed. A
layer component read `i18n.language` unguarded, and core's tests mock
`react-i18next` with only `t` — so a layer could break core's suite from
outside it. The guard belongs in the layer and shipped there; the assertions
here now scope to the comment thread, because an extension section legitimately
repeats a comment's text.
